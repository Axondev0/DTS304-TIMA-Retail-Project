# TIMA Retail Store Management System

DTS 304 – Data Management I

## Project Overview
A retail data management project demonstrating database design,
SQL queries, indexing, and Python search algorithms.

## Technologies
- Python
- MySQL
- XAMPP / phpMyAdmin
- Git and GitHub

## Features
- Customer purchase data management
- Relational database implementation
- Database indexing
- SQL date-range and category queries
- Sequential and binary search comparison

## Python Execution
Run:

python Search_algorithms.py
